# Future production discovery checklist

Discovery questions only. None of these are prototype commitments or implemented features.

- [ ] Company SSO and employee eligibility (the prototype demo selector is not authentication).
- [ ] Privacy: contact details, precise-location sharing, data retention, and deletion rules.
- [ ] Safety, support, and abuse-handling policies.
- [ ] Production database and hosting (SQLite is single-local-deployment only), backups, and migrations.
- [ ] Monitoring, logging, alerting, and operational ownership.
- [ ] Accessibility standards and audit.
- [ ] Security and privacy review and Rogers approvals before any real data is used.
- [ ] Whether notifications, recurring rides, payments, or admin tools are warranted.
- [ ] App-store publishing and release process.
